# Real photo dataset (to be collected by the team)

This folder is intentionally empty of photos. Collect them following `scripts/collect_cv_dataset.md`, add a
`metadata.csv` (columns as in `metadata.template.csv`) and run `python -m qrshield train-cv --real data/cv_images`.

Do **not** commit raw photos of other people's property or anything with faces/number plates; commit only a tiny
consented sample, if any.

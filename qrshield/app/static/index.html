Why QRshield

A QR code is a link you cannot read

Attackers hide behind that. They publish look-alike links no blocklist has seen, and paste stickers over real codes on parking meters, menus and payment stands. One check is never enough.

M1

Link analysis

A calibrated machine-learning model plus brand-impersonation rules catches look-alike and scam links, UPI payee tricks and shortener hops.

  • Character n-gram + LightGBM
  • Official-domain brand rules
  • SSRF-safe shortener look-ahead
M2

Sticker check

The photo is flattened onto the QR plane and measured for the tell-tale signs of a code pasted over another one.

  • Edges, shadow, paper colour, grain
  • Gloss and hidden-original fragments
  • Visual evidence overlay
M3

Signature check

Businesses sign their codes. QRshield verifies the signature, the certificate chain and the domain binding against a pinned root key.

  • Root-signed issuer certificates
  • Signed, versioned revocation list
  • Key rotation, fail-closed

Decision engine

Cryptography first. Evidence second. Always explained.

The engine never hides behind a score. Hard facts — a valid or forged signature — outrank statistics, and visual evidence alone can never block a code.

        How it works

        Three layers, one honest verdict

        What each layer measures, how the results are fused, and what QRshield cannot do.

        Why scanning a QR code is risky

        A QR code is just a link you cannot read. Attackers use that two ways: new look-alike links that no blocklist knows yet, and stickers pasted over real codes at parking meters, menus and payment stands. A URL checker cannot see a sticker; a camera check cannot read a link; and signed codes only help businesses that sign.

        Three independent layers

        M1
        Link analysis

        A calibrated model over lexical features and character patterns, brand-impersonation rules (official domains vs look-alikes), UPI payee checks, and an SSRF-safe look at shorteners.

        M2
        Sticker check

        The photo is rectified onto the QR plane and measured: straight sticker borders, shadow, paper colour, grain, highlights, and original-code fragments peeking out.

        M3
        Signature check

        Ed25519 signatures bound to a certified domain, verified against a pinned root key with a signed revocation list. Failing verification is stronger evidence of attack than being unsigned.

        What QRshield cannot do

        • A perfectly fitted sticker over an unsigned code looks like a genuine sticker. The sticker check catches imperfect covers; the signature check catches it only for businesses that sign.
        • A signature proves who issued a payload, not that the physical code was never copied (replay). Location binding, expiry and the sticker check limit this.
        • The link model is statistical; it will misjudge some legitimate and some malicious links.

        Privacy by design

        Photos are analysed in memory and never stored. Reports keep only the link, your label and an optional note — no photo, no identity. Scan history lives only in your browser.

        Safe look-ups

        When QRshield follows a shortener it resolves DNS once, refuses private addresses and connects to the validated IP, so a hostile link cannot probe your network.

        What QRshield cannot do

        A perfectly fitted sticker

        Over an unsigned code it looks like a genuine sticker. The sticker check catches imperfect covers; the signature check catches it only for businesses that sign.

        Replay of a valid code

        A signature proves who issued a payload, not that the physical code was never copied. Location binding, expiry and the sticker check limit this.

        Statistical link model

        It will misjudge some legitimate and some malicious links, which is why it is one layer of three and not the whole verdict.

        FAQ

        Questions, answered plainly

        Short answers about what QRshield checks, what it keeps and where it can be fooled.

        What is quishing?

        Quishing is phishing through QR codes. The code hides a malicious link, or a sticker is pasted over a genuine code so scanners land on the attacker’s page.

        Does QRshield open the link for me?

        No. It shows the destination and the verdict first. For suspicious or blocked codes you must explicitly confirm before the link is offered.

        Do you store my photos?

        No. Photos are analysed in memory and discarded. Scan history is stored only in your own browser and can be cleared at any time.

        What is a signed QR code?

        An ordinary link with one extra parameter holding an Ed25519 signature. Any phone camera still opens it, but QRshield also verifies the signature, the certificate chain and the domain binding.

        Why can a sticker alone not BLOCK a code?

        Visual evidence is probabilistic. To avoid false alarms, a sticker finding can raise the risk to suspicious, but only hard facts such as a forged signature or a clearly malicious link lead to BLOCK.

        Can I use the live camera on my phone?

        Browsers allow the live camera only over HTTPS or localhost. On a phone, use Photo → Take photo, or run the server with --https and open the printed address.

        How does the model learn from reports?

        Reports wait in a review queue. Only approved ones join the training data, and a retrained model is promoted only if it beats the active model on a fixed benchmark and canary links.

        Where do I find the admin token?

        It is printed in the server console at start-up and saved in .qrshield/admin_token. You can set your own with QRSHIELD_ADMIN_TOKEN.
